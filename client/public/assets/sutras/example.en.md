# How to add sutras

This is a placeholder. Put each text in this folder as a `.md` or `.txt` file and list it in `index.json`.

Blank lines separate paragraphs.
Single line breaks are kept,
so verses keep their shape.

## Translations

Give translations of the same text the same `group` and a different `lang`, e.g. `heart.en.md` and `heart.zh.md`. The reader picks the one matching the visitor's language and falls back to English.
